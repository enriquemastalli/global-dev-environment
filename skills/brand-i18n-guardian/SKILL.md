# Guardián de Marca y Traducciones

## Reglas Estrictas:
1. **Cero Textos Hardcodeados:** Todo texto debe provenir de los archivos de internacionalización (`es.json`, `en.json`).
2. **Glosario de Marca:** Usa SIEMPRE "Humano Sintético". Nunca uses "Bot", "Chatbot" o "Agente virtual". Nunca uses "Crear prompt"; usa "Diseñar Genoma" o "Evolucionar".
3. **Manejo de Errores Amigable:** Los mensajes de error de la API deben traducirse a un lenguaje de negocio empático en el frontend.
