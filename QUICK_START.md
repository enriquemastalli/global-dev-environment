# Quick Start — Global Development Environment

## Instalación en 30 Segundos

```bash
curl -fsSL https://raw.githubusercontent.com/enriquemastalli/global-dev-environment/main/install.sh | bash
```

## ¿Qué Es?

Un **Entorno Global de Desarrollo** universal que aplica a **CUALQUIER proyecto**:

- ✅ **Consistente** — Mismo en 100 máquinas
- ✅ **Universal** — Para cualquier tipo de proyecto
- ✅ **Portable** — Se instala en 30 segundos
- ✅ **9 Skills Integrados** — Carga automática según contexto
- ✅ **Protocolo Senior** — Debugging científico, error handling robusto

## Después de Instalar

```bash
# Validar un proyecto
~/.opencode/bin/validate-project.sh /ruta/al/proyecto

# Auto-crear AGENTS.md si falta
~/.opencode/bin/auto-create-agents-md.sh /ruta/al/proyecto

# Verificar instalación
~/.opencode/bin/verify-installation.sh
```

## Para Equipos

Comparte con tu equipo:

```bash
# Opción A: Una línea
curl -fsSL https://raw.githubusercontent.com/enriquemastalli/global-dev-environment/main/install.sh | bash

# Opción B: Descargar y instalar
git clone https://github.com/enriquemastalli/global-dev-environment.git
cd global-dev-environment
bash install.sh

# Opción C: Archivo comprimido
# Descargar desde releases y ejecutar: bash install.sh
```
